# AI Workload Research Frontend

React + Vite frontend for inspecting AI inference telemetry, pod cluster resource status, experiment configurations, Prometheus live streams, and empirical research results.

## Tech Stack
- React 18
- Vite
- Lucide-React
- Vanilla CSS Design System (Dark mode, glassmorphism, responsive)

## Running Locally
```bash
npm install
npm run dev
```
Accessible at `http://localhost:5173`.
